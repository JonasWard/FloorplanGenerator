# FloorplanGenerator
A collection of tools to use the collaborative AI floorplan generator API

# To install Grasshopper plugin copy Grasshopper Plugin/JLP folder to grasshopper libraries folder  
Grasshopper Plugin/Templates is optional  
Typically in %appdata%Roaming/Grasshopper/Libraries  

# Web UI
`UI/` holds a browser floorplan editor that runs the Rust backend as WebAssembly. See [UI/README.md](UI/README.md).
